# 原PDF资料库 v0.7.0

2026-10-22 用户授权参考 https://www.easteat.com/ 的公开页面建设个人资料库，内容由用户提供。通过公开 HTML、搜索表单与实际浏览器观察分析导航、搜索入口、分类封面卡片、目录与原文入口；未运行REA，未获取或声称还原网站服务器源码，未进入付费内容。

## 已实现

- 首页固定导航、搜索区、分类封面书架、年份筛选、原文搜索结果、文章/页面来源和移动端适配。
- 管理界面批量逐文件上传 PDF，显示上传进度；沿用现有 x-sync-token 与同源写入保护，不增加读者账号。
- PyMuPDF提取原有文字与内嵌目录；原PDF文件原样保存。中文 trigram FTS5，短词使用转义后的字面量 LIKE，多个空格分隔的词均需匹配；结果分页，不只取前若干条。
- 有内嵌目录时保存标题、层级、实际PDF起止页；没有目录时明确按页匹配，管理中可编辑书名/分类/年份/期号与文章目录。搜索命中后定位包含关键词的PDF页。
- 原文按页渲染PNG供手机/电脑统一阅读，支持目录、翻页、页码、缩放与本机进度。原文件可单独打开。
- SHA256检测完全相同文件，包含回收站条目。删除仅软删除，原PDF和索引保留，可恢复；本版不实现永久删除。
- 服务重启将中断索引恢复为排队状态。按用户后续要求，旧转换器、阅读器、旧接口、/legacy和桌面更新发布包均移除；生产数据保留。

## 边界与后续

尚未实现扫描件OCR、语义检索、无内嵌目录的自动文章划分、AI总结、25GB大库负载验证、断点续传。图片页/文字很少页标记待OCR，混合文件已提取文本仍可检索；这类标记不代表每页都一定是扫描件。初版只保证原PDF阅读完整，不能保证原有文本层提取完整准确。目录定位依赖PDF内嵌书签或人工维护；文章范围按下一条同级/上级条目的前一页推导，需实际样本验收。

页面不是东方美食的像素级复制：使用自有名称和独立实现的界面，参考其信息结构与浏览路径，未复制其文章、品牌图片或目录数据库。真实文件尚未批量导入，测试只用合成PDF。

## 部署

保留原有 ci.yml 成功后 timer 更新机制、域名、端口和 systemd 服务。requirements.txt 新增 PyMuPDF。新数据自动建立在 /var/lib/chen-cook/reader/original-library 下；文件 files/<随机ID>.pdf，SQLite catalogue.sqlite3。不需要把原PDF提交GitHub。现有服务对该数据目录已有写入权限。

COOK_SYNC_TOKEN/原同步密钥可直接用于管理上传，不在聊天、日志或Git中读取。浏览不需要密钥，与用户既有要求一致。

本地检查与CI、生产health必须分别报告。浏览器验收为tests/library_browser_acceptance.py，只使用合成数据。旧测试已删除。
